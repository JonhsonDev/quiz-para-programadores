# Quiz para Programadores

Projeto desenvolvido para demonstrar conhecimentos em HTML, CSS e JavaScript.

## Objetivos
- Desenvolver uma interface responsiva.
- Praticar manipulação do DOM com JavaScript.
- Aplicar boas práticas de HTML semântico e CSS.
- Criar uma experiência de usuário agradável.

## Tecnologias
- HTML5
- CSS3
- JavaScript
